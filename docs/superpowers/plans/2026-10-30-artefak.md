# Runova Bagian 2: Membaca Artefak — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pengguna mengunggah `.jar`, binary ELF, atau `.tar.gz`; Runova menyimpannya sementara dan mengembalikan laporan: jenis, versi Java minimal, port, env yang dirujuk, dan masalah yang menghalangi deploy.

**Architecture:** Paket murni `internal/artifact` (tanpa I/O jaringan, tanpa store) memeriksa file di disk dan mengembalikan `Report`. `internal/store` menyimpan unggahan sementara (`uploads`). `internal/api` menerima multipart secara streaming ke `$RUNOVA_DATA/tmp/`. Tidak ada eksekusi file yang diunggah.

**Tech Stack:** Go stdlib: `archive/zip`, `archive/tar`, `compress/gzip`, `debug/elf`, `bufio`.

**Spec:** `docs/spec.md` §3 (setelan unggahan, runtime), §4.

**Bergantung pada:** Bagian 1 (store, auth, api, aktivitas).

## Global Constraints

- Ukuran unggahan maks = `Settings.UploadLimitMB` (bawaan 500 MB). Untuk `.tar.gz`, total isi terekstrak juga ≤ batas itu.
- Java: major 52→8; 53–55→11; 56–61→17; 62–65→21; 66–69→25; >69 → masalah "Butuh Java lebih baru dari 25". Entri `META-INF/versions/**` (multi-release) diabaikan.
- ELF yang diterima: `ELFCLASS64`, `EM_X86_64`, `ET_EXEC` atau `ET_DYN`. Tanpa `PT_INTERP` = `static`; interpreter `/lib64/ld-linux-x86-64.so.2` = `glibc`; lainnya ditolak.
- Port bawaan `8080`.
- Nama env: `^[A-Z][A-Z0-9_]{1,63}$`. Rahasia bila komentar baris `# secret` di `.env.example` atau nama mengandung `PASSWORD`, `SECRET`, `TOKEN`, `KEY`.
- Unggahan sementara kedaluwarsa 24 jam; dibersihkan saat start dan tiap jam.
- Pesan masalah dalam Bahasa Indonesia, dan laporan tidak pernah memuat isi file selain nama env dan nilai bawaan dari `.env.example`.

## Review Focus

- **`.tar.gz` dengan `../` atau symlink** → ditolak "Arsip berisi path tidak aman", tidak ada file di luar folder unggahan. Test di Task 3 (`TestTarRejectsTraversalAndLinks`).
- **Bom gzip** (kecil terkompresi, raksasa terekstrak) → berhenti saat melewati batas, folder dibersihkan. Test di Task 3 (`TestTarSizeLimit`).
- **Fat JAR Spring Boot dengan dependensi Java 17 tapi kelas aplikasi Java 8** → minimal 17 (nested jar ikut dipindai). Test di Task 1 (`TestJarNestedLibRaisesMinimum`).
- **Binary Windows/macOS/ARM** → masalah yang menyebut jenisnya ("File Windows (.exe) tidak bisa dijalankan di Linux", "Binary ARM64, server ini amd64"), bukan "format tidak dikenal". Test di Task 2 (`TestELFRejections`).
- **Unggahan terputus di tengah** → file sementara terhapus, tidak ada baris `uploads`. Test di Task 4 (`TestUploadAbortCleansUp`).

### Task 1: Inspeksi JAR

**Files:**
- Create: `internal/artifact/report.go`, `internal/artifact/jar.go`, `internal/artifact/jar_test.go`, `internal/artifact/testutil_test.go`

**Interfaces:**
- Produces:
  - `type Kind string`: `KindJar = "jar"`, `KindStatic = "static"`, `KindGlibc = "glibc"`.
  - `type EnvVar struct{ Name, Default string; Secret bool; Source string }` (Source: `"env.example"`, `"properties"`, `"scan"`).
  - `type Report struct{ Kind Kind; FileName string; Size int64; SHA256 string; MinJava int; MainClass string; Port int; PortSource string; Env []EnvVar; Problems []string }` (JSON snake_case). `func (r Report) OK() bool` = `len(Problems)==0`.

Aturan: manifest wajib punya `Main-Class` (atau `Start-Class` untuk Spring Boot, dicatat sebagai `MainClass`). Kelas dipindai di akar dan `BOOT-INF/classes/`; nested jar di `BOOT-INF/lib/*.jar` dan `WEB-INF/lib/*.jar` dibuka dari memori (lewati yang > 64 MB). `server.port` dari `application.properties` / `application.yml` di akar atau `BOOT-INF/classes/` (`${PORT:9000}` → port 9000 dan env `PORT`). `${NAME}` / `${NAME:default}` di file properti → `EnvVar{Source:"properties"}`.

### Task 2: Inspeksi ELF dan scan env binary

**Files:**
- Create: `internal/artifact/elf.go`, `internal/artifact/scan.go`, `internal/artifact/elf_test.go`

**Interfaces:**
- Consumes: Task 1 (`Report`, `EnvVar`, `Kind`).
- Produces: `func InspectBinary(path string) (Report, error)`; `func Detect(path string) (format string, err error)` → `"jar"`, `"elf"`, `"targz"`, `"pe"`, `"macho"`, `"unknown"` dari magic bytes (`PK\x03\x04`, `\x7fELF`, `\x1f\x8b`, `MZ`, `\xfe\xed\xfa\xce|\xfe\xed\xfa\xcf|\xcf\xfa\xed\xfe|\xca\xfe\xba\xbe`).
- Test helper `buildELF(t, machine elf.Machine, class elf.Class, interp string, extra ...string) string`: ELF minimal (header + satu `PT_LOAD`, opsional `PT_INTERP`), lalu string `extra` ditempel di akhir file.

Scan env (hanya bila file memuat salah satu penanda `os.Getenv`, `syscall.Getenv`, `std::env::var`, `getenv`): ambil string ASCII yang dibatasi byte non-cetak, cocok `^[A-Z][A-Z0-9]*_[A-Z0-9_]+$` (wajib ada `_`) atau persis `PORT`, panjang 4–64, tidak di daftar abaikan (`GODEBUG`, `GOMAXPROCS`, `GOTRACEBACK`, `GOGC`, `GOMEMLIMIT`, `GOROOT`, `GOPATH`, `RUST_BACKTRACE`, `RUST_LIB_BACKTRACE`, `LD_LIBRARY_PATH`, `LD_PRELOAD`, `SSL_CERT_FILE`, `SSL_CERT_DIR`, `HTTP_PROXY`, `HTTPS_PROXY`, `NO_PROXY`, `TZ`, `HOME`, `PATH`, `USER`, `LANG`), dan tidak berawalan `GO`, `CGO_`, `RUST_`, `LC_`, `XDG_`. Maks 50, `Source:"scan"`.

### Task 3: `.tar.gz`, `.env.example`, dan pintu masuk tunggal

**Files:**
- Create: `internal/artifact/targz.go`, `internal/artifact/envfile.go`, `internal/artifact/inspect.go`, `internal/artifact/targz_test.go`, `internal/artifact/inspect_test.go`

**Interfaces:**
- Consumes: Task 1–2.
- Produces:
  - `func ParseEnvExample(r io.Reader) ([]EnvVar, error)` — `NAME=value` (nilai jadi `Default`, kutip `"`/`'` dilepas), `export NAME=`, baris kosong/`#` diabaikan; komentar `# secret` di baris sebelumnya atau di ujung baris → `Secret`.
  - `func ExtractTarGz(src, dir string, limit int64) (artifactPath, envExample string, err error)` — `envExample` kosong bila tidak ada. Error terketik: `ErrUnsafeArchive`, `ErrTooLarge`, `ErrArchiveContents`.
  - `func Inspect(path, fileName, workDir string, limit int64) (Report, string /*artifact path to keep*/, error)` — gabungan: deteksi format; `.tar.gz` diekstrak ke `workDir`; mengisi `FileName`, `Size`, `SHA256` artefak; env digabung prioritas `env.example` > `properties` > `scan` (nama sama: sumber prioritas lebih tinggi menang; `Secret` di-OR). Port binary dari `PORT` di `.env.example` bila angka 1–65535 (`PortSource "env.example"`).

Isi `.tar.gz` yang sah: tepat satu artefak (`.jar` atau ELF) di akar, opsional `.env.example`, opsional file lain yang diabaikan (`README*`, `LICENSE*`). Selain itu → `ErrArchiveContents` "Arsip harus berisi satu file .jar atau binary di akarnya". Entri non-regular (symlink, hardlink, device) atau path dengan `..`/absolut → `ErrUnsafeArchive`.

### Task 4: Unggahan lewat API

**Files:**
- Create: `internal/store/uploads.go`, `internal/store/uploads_test.go`, `internal/api/uploads.go`, `internal/api/uploads_test.go`
- Modify: `internal/store/store.go` (tabel `uploads`), `internal/store/activity.go` (aksi `ActUpload = "upload"`), `internal/api/api.go` (route, `Config.DataDir string`), `cmd/runova/main.go` (isi `DataDir`, pembersihan tiap jam)

**Interfaces:**
- Consumes: Task 3 `artifact.Inspect`; Bagian 1 `Settings.UploadLimitMB`, `Settings.Runtimes`.
- Produces:
  - Tabel `uploads(id TEXT PK /*NewToken()[:24]*/, user_id FK CASCADE, dir TEXT, artifact_path TEXT, report TEXT /*JSON*/, created_at)`.
  - `(*Store).CreateUpload(ctx, Upload) error`, `Upload(ctx, id string, userID int64) (Upload, error)` (milik pengguna lain → `ErrNotFound`), `DeleteUpload(ctx, id)`, `ExpiredUploads(ctx, before int64) ([]Upload, error)`; `type Upload struct{ ID string; UserID int64; Dir, ArtifactPath string; Report artifact.Report; CreatedAt int64 }`.
  - `POST /api/uploads` (multipart, field `file`) → 201 `{"id":..., "report": Report, "allowed_java":[8,11,...]}`; `allowed_java` = runtime Java yang diizinkan admin dan ≥ `MinJava`. Runtime jenis itu dimatikan admin → tambah masalah "Admin menonaktifkan runtime <x> di server ini". Badan > batas → 413 "File melebihi batas <N> MB".
  - `DELETE /api/uploads/{id}` → 200, folder dihapus.
  - `api.CleanupUploads(ctx, st, now) error` dipanggil `serve` saat start dan tiap jam.

Unggahan ditulis ke `$RUNOVA_DATA/tmp/<id>/` (mode 0700) memakai `r.MultipartReader()` (streaming, bukan `ParseMultipartForm`), dibatasi `http.MaxBytesReader(limit+1 MiB)` dan `io.LimitReader` file.
