# Runova Bagian 6: Panel Web — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Panel web yang tertanam di binary, mewujudkan `preview-dashboard.html` di atas API Bagian 1–5: login, daftar aplikasi, wizard deploy 4 langkah, detail aplikasi (7 tab), Database, Aktivitas, Pengguna, Server, notifikasi, mode terang/gelap, tata letak HP.

**Architecture:** SPA vanilla (ES modules, tanpa framework, tanpa proses build) di `web/`, di-`embed` ke `internal/api` lewat `web/embed.go`. Router hash (`#/apps`, `#/apps/12/env`, …). Satu modul per halaman; `web/js/api.js` satu-satunya tempat `fetch`. CSS dipindahkan dari preview ke `web/css/` dan dipecah per area. Semua aset (IBM Plex, ikon Lucide, logo Devicon) **di-vendor** ke `web/vendor/` — panel tidak memuat apa pun dari CDN, sehingga jalan di server tanpa internet keluar.

**Tech Stack:** HTML/CSS/JS biasa; ikon: sprite SVG Lucide yang dihasilkan sekali oleh `go run ./cmd/genicons` (hanya ikon yang dipakai); verifikasi lewat browser headless (Chromium via Playwright/`browser` tool) di uji asap.

**Spec:** `docs/spec.md` seluruhnya untuk perilaku; `preview-dashboard.html` untuk tampilan (sumber kebenaran visual: palet, tipografi, jarak, komponen, perilaku HP).

**Bergantung pada:** Bagian 1–5 (API).

## Global Constraints

- Tanpa dependensi JS runtime dan tanpa CDN. Aset vendor beserta lisensinya di `web/vendor/LICENSES.md` (Lucide ISC, Devicon MIT, IBM Plex OFL).
- Teks antarmuka Bahasa Indonesia, sama dengan preview.
- Header keamanan dari server untuk semua aset dan halaman: `Content-Security-Policy: default-src 'self'; img-src 'self' data:; style-src 'self'; script-src 'self'; connect-src 'self'; frame-ancestors 'none'`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: same-origin`. Konsekuensi: tanpa `style=""` inline dan tanpa `onclick=""` di HTML; lebar bar memakai `element.style.setProperty` dari JS (diizinkan CSP karena CSSOM, bukan atribut).
- Aset statis di-cache dengan nama berisi hash konten (`app.<hash>.js`) yang dihitung saat start dari `embed.FS`; `index.html` `no-store`.
- Breakpoint HP ≤ 760 px: navigasi bawah (Aplikasi, Database, Deploy, Pengguna/Aktivitas, Lainnya), wizard dengan tombol Kembali/Lanjut menggantikan navigasi bawah — persis preview.
- Mode gelap: mengikuti `prefers-color-scheme`, bisa dipaksa dari menu akun, disimpan di `localStorage['runova.theme']`.
- Setiap teks dari server dimasukkan lewat `textContent` atau helper `h(tag, attrs, ...children)`; `innerHTML` hanya untuk templat statis tanpa data.
- Polling: daftar aplikasi dan detail aplikasi tiap 5 detik saat tab terlihat (`document.visibilityState`); lonceng tiap 30 detik. Log dan terminal lewat WebSocket.
- Terminal: `xterm.js` di-vendor (MIT) — satu-satunya pustaka JS pihak ketiga.

## Review Focus

- **Nama aplikasi, env, atau log berisi HTML/skrip** (`<img onerror>`) → tampil sebagai teks. Test di Task 2 (`h()` unit test) dan uji asap Task 6 (env bernilai `<script>`).
- **Sesi kedaluwarsa saat halaman terbuka** → permintaan berikut 401 → kembali ke layar login dengan pesan "Sesi berakhir, silakan masuk lagi", lalu kembali ke rute semula setelah login. Test di Task 2 (`api.js` test).
- **Unggahan besar di koneksi lambat** → progres persen tampil (XHR `upload.onprogress`), tombol Batal membatalkan, dan file > batas ditolak di klien sebelum dikirim dengan pesan sama dengan server. Uji asap Task 3.
- **Pengguna biasa membuka `#/users` atau `#/server` langsung** → diarahkan ke `#/apps`, menu admin tidak tampil. Uji asap Task 5.
- **HP 360 px** → tidak ada scroll horizontal di semua halaman (diperiksa `scrollWidth == clientWidth` seperti saat membuat preview). Uji asap Task 6.
