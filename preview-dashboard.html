Lewat proxy Cloudflare (awan oranye). IP server tersembunyi dan dapat perlindungan DDoS. Port 80 dan 443 tetap harus terbuka untuk Cloudflare.

  1. Buat DNS record, mula-mula tanpa proxyCloudflare → DNS → Records → Add record
    TypeA
    Namebilling
    IPv4 address203.0.113.15
    Proxy statusDNS only dulu
  2. Tunggu sampai Runova menampilkan "HTTPS aktif"Caddy perlu menerbitkan sertifikat pertama selagi server bisa diakses langsung.
  3. Nyalakan proxyEdit record yang sama → Proxy status → Proxied
  4. Atur mode SSLCloudflare → SSL/TLS → Overview → Configure
    Encryption modeFull (strict)
Jangan pakai mode Flexible, karena akan terjadi redirect berulang. Untuk perpanjangan sertifikat, Caddy butuh jalur /.well-known/acme-challenge/ tetap bisa diakses lewat HTTP. Kalau domain ini pakai aturan redirect ke HTTPS di Cloudflare, kecualikan jalur itu.

Untuk server tanpa IP publik atau tanpa port terbuka. Server membuka koneksi keluar ke Cloudflare, dan HTTPS diurus Cloudflare. Runova melayani domain ini lewat HTTP biasa.

  1. Buat tunnel sekali untuk server iniCloudflare → Networking → Tunnels → Create a tunnel. Jalankan perintah instalasinya di server Runova. Tunggu status Healthy.
  2. Tambah route untuk aplikasi iniPilih tunnel → tab Routes → Add route → Published application
    Subdomainbilling
    Domainperusahaan.co.id
    Pathkosongkan
    Service URLhttp://localhost:80
  3. Simpan, lalu tekan Periksa di bawahCloudflare membuat DNS record-nya otomatis.
Isi Path hanya kalau aplikasi memang melayani prefix itu sendiri, misalnya /api. Cloudflare meneruskan path apa adanya, tidak dipotong. localhost:80 adalah Caddy di server Runova, yang lalu meneruskan ke aplikasi berdasarkan nama domain.
